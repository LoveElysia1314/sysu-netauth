# Windows 安装与维护

支持 Windows 10/11 x64 和 ARM64。安装、配置及服务管理需要管理员权限。

## 安装

从[发布页](https://github.com/LoveElysia1314/sysu-netauth/releases)下载与系统架构对应的 `Setup` 文件：x64 选择 `windows_x64`，Windows on ARM 选择 `windows_arm64`。

1. 运行安装包，按提示完成安装。
2. 打开 SYSU NetAuth，填写 NetID 和密码，点击“认证”。默认自动选择已连接的有线网卡。
3. 启用“服务启动后自动认证”，即可关闭界面并由服务保持认证。

手动选卡时，程序保存设备 ID。网卡插拔后列表自动刷新；所选设备被拔出时显示为“未连接”，不会自动保存为另一个设备。

当前服务运行期间，手动断开后，插拔网卡和系统唤醒都保持断开；点击“认证”才会恢复认证。重新启动服务时按自动认证设置执行。修改账户或网卡后点击“认证”，会保存配置并启动一次认证。

## 配置与更新

账户和网卡信息编辑后，点击“认证”保存并发起认证；已认证且账户未变时，按钮显示“重新认证”。常规选项修改后立即保存。账户区的“退出程序”关闭界面，后台服务继续运行。

配置和日志位于 `%ProgramData%\SYSUNetAuth`，仅 SYSTEM 和管理员可访问。`config.json` 包含明文凭据，分享日志时请勿附带该文件。

服务按计划检查正式版更新，也可点击“检查更新”主动查询。

左下方的“常规设置”集中放置登录启动、联网通知和更新选项；右下方的“应用信息”显示当前版本和更新提示，提供检查更新、运行日志和更新日志三个按钮。勾选“自动检查更新”后，服务按计划检查正式版；“有新版本时通知”单独控制更新提醒。两个选项默认开启，修改后立即保存。关闭自动检查后仍可点击“检查更新”。

后台服务负责日常认证，独立通知助手在用户登录后运行。退出状态程序后，认证和通知继续工作。可选开启“开机后启动界面程序”（默认关闭），在进入桌面后驻留托盘；“开机后隐藏配置窗口”默认开启。认证状态通知默认关闭，勾选“认证状态变化后通知”后，助手按此设置发送。

正式版更新提醒独立于认证状态通知：后台服务自动检查，助手对每个新版本提醒一次，点击通知打开发布说明。“更新日志”优先展示未忽略的新版本说明，其余情况展示当前版本说明。托盘菜单“软件更新”还可查看新版说明或忽略该版本。通知助手平时没有窗口或常驻托盘图标，发送通知时短暂使用通知区域。

重试间隔由后台服务管理。菜单中可选系统单色或彩色状态图标，默认单色并跟随任务栏外观。

“应用信息”提供“运行日志”：读取最近服务日志，长度受限时优先保留最新记录，遮盖当前账号和密码；分享日志前请检查个人信息。

## 系统有线认证

Windows 自带的有线自动配置服务可能占用同一网卡。如果此前启用了系统有线认证，先停用该服务，再使用本客户端。管理员 PowerShell：

```powershell
Stop-Service dot3svc
Set-Service dot3svc -StartupType Disabled
```

这不会停止 Wi-Fi 服务。以后需要恢复 Windows 系统有线认证时，先停止 SYSU NetAuth 服务，再将 `dot3svc` 改为 `Manual` 并启动。

## 连接通知

主动点击连接后，认证成功会显示通知。自动重连在 5 秒内恢复时保持静默，界面和托盘仍实时更新状态。

连接持续中断 5 秒后提醒一次，恢复后再提示一次。重试不会重新开始中断计时，手动断开和系统休眠不会触发断线提醒。防抖只影响通知，自动重连照常执行。

可通过“认证状态变化后通知”开关关闭这些提醒。

## 故障排查

| 现象 | 检查方法 |
| --- | --- |
| 无法认证 | 确认有线网卡、NetID 和密码，检查系统有线认证是否占用网卡，并退出其他认证客户端 |
| 界面提示服务未连接 | 在管理员终端执行 `sc.exe query SYSUNetAuth`，需要时执行 `sc.exe start SYSUNetAuth` |
| 唤醒后未恢复认证 | 检查自动认证和后台服务状态，并按[恢复排查](RESUME.md)查看日志 |
| 安装或卸载失败 | 查看 `%TEMP%` 中的 Setup Log 或 Uninstall Log |

连接日志为 `%ProgramData%\SYSUNetAuth\service.log`。可使用 `Setup.exe /LOG="C:\path\setup.log"` 或安装目录中的 `unins000.exe /LOG="C:\path\uninstall.log"` 指定安装、卸载日志的位置。

## 升级与卸载

升级时运行新的 Setup 安装包，沿用现有目录和设置。安装程序会停止应用与服务后替换文件。

从 v0.6.3 升级且系统仍装有 Npcap 时，安装完成页提供可选的清理入口，打开系统应用列表供手动卸载。清理选项默认关闭；使用 Wireshark 等依赖 Npcap 的工具时，可保留该驱动。

在 Windows“已安装的应用”中卸载 SYSU NetAuth。卸载会清理通知助手及其登录任务，向导可删除保存的账号和设置。
